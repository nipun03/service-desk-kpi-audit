# Service desk KPI audit

See how short abandons and denominator choices affect reported abandonment.

Open index.html locally, or serve this directory as a static site. No installation or backend is required. For GitHub Pages, publish the repository root from the main branch.

Gross abandonment includes all abandons. The adjusted definition removes short abandons from both numerator and denominator. A zero denominator returns N/A. All inputs are synthetic.
